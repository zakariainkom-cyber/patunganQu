Pengaturan Firebase Real-time Cloud Sync

Hubungkan database Firebase gratis milik Anda agar data tersinkronisasi otomatis dengan teman-teman

Cara Gratis Membuat Database Firebase (Kurang dari 2 Menit):
  1. Buka console.firebase.google.com dan login dengan Google.
  2. Klik Add Project → Pilih nama project (misal: "kopikas-app") → Klik Continue.
  3. Masuk ke Firestore Database → Klik Create Database → Pilih mode Start in Test Mode.
  4. Masuk ke Project Settings (Ikon Gear) → scroll ke paling bawah → klik ikon Web </> → Salin objek firebaseConfig dan tempel di kotak di bawah ini:
